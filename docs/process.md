## 2. 每一步的过程

### 2.1 方案 C:多模态直接看图

| 过程 | 内容 |
|---|---|
| 先排查 | 担心 DeepSeek 不支持图片。做对照实验:同一个问题带图/不带图。`deepseek-flash` 带图读对流水号、不带图回答"看不到图片" → 支持;`deepseek-v4-pro` 两种情况都"看不到" → 不支持 |
| 坑 1 | 第一次探测时 `max_tokens=60` 被"思考"吃光,返回空字符串,差点误判成"不支持"。调大后才看到真实回答 |
| 定尺寸 | 实测最长边 512/1024/2048 → 约 210/440/1000 token,三者都读对 20 位发票号 → 原图 PNG 发送,最长边 >1600 才缩小 |
| 实现 | 把 B 的"校验 + 重试一次 + 降级"抽成 `chat_with_retry`,B、C 共用;C 的提示词只改输入相关部分,字段定义一字不改 |
| 坑 2 | 用脚本生成 C 提示词时,替换规则没覆盖到"小写金额被 OCR 读坏"这句,断言"不含 OCR"报错,补了一条替换 |
| 验证 | 开发集 18 张 → 冻结 → SUBSET10 跑一次;2 个新单测(缩放、调用视觉模型) |
